## Sobre o projeto

O Decisão Estratégica é um projeto de BI que busca identificar o município de Santa Catarina com maior potencial para receber uma nova filial de uma grande empresa varejista de materiais de construção.

## O problema

**Qual município de SC tem maiores chances de retorno financeiro para instalar uma filial?**

A ideia é comparar os municípios com base em dados reais, considerando o mercado consumidor, a concorrência, o crescimento e o poder de compra.

## Tecnologias

- **Python:** coleta e tratamento dos dados.
- **APIs públicas:** obtenção de dados oficiais.
- **PostgreSQL:** armazenamento e consultas SQL.
- **Power BI:** análise dos indicadores e visualização dos resultados.
- **Git e GitHub:** versionamento e documentação do projeto.

## Resultado esperado

Desenvolver um dashboard interativo com um ranking dos municípios catarinenses, permitindo comparar indicadores e identificar as localidades com maior potencial para a abertura de uma filial.

O ranking será uma estimativa baseada nos indicadores selecionados, não uma garantia de retorno financeiro.
